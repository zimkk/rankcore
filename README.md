# RankCore

**Make your coding agent understand how your website should be discovered — then let it fix the code.**

RankCore gives Claude Code, Codex, Cursor and other coding agents a current search/AI-search workflow plus a deterministic local audit engine. No RankCore account. No extra LLM API. No SEO API required.

## Installation

macOS / Linux:
```bash
curl -fsSL https://rankcore.dev/install.sh | sh
```

Windows PowerShell:
```powershell
irm https://rankcore.dev/install.ps1 | iex
```

## Usage

After installation, open your web project in your coding agent and type:

```
/rank
```

RankCore will automatically:
1. Understand your project and product.
2. Conduct external search and market research (if your agent has web access).
3. Run a deterministic local technical SEO audit.
4. Recommend fixes based on evidence.
5. Apply fixes through your agent and verify them.
